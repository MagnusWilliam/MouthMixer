# MouthMixer

Hum, whistle or beatbox while you work. MouthMixer listens in the background, keeps only the musical
moments, turns them into clean notes and drum hits, and builds finished, original game music around
them in the style you ask for. A built-in critic filters out weak ideas and bad mixes, so you only hear
the best three options and steer with suggestions instead of editing.

**Status:** planning. Nothing is built yet.
