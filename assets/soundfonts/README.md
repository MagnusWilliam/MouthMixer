# Instrument sounds

`GeneralUser-GS.sf2` is **GeneralUser GS v2.0.3** by S. Christian Collins
(https://www.schristiancollins.com), copied from https://github.com/mrbumpy409/GeneralUser-GS at
commit 684543d. Licence: `GeneralUser-GS-LICENSE.txt` — free to use for music creation, private or
commercial, and to ship in software. The author asks that we keep our own copy instead of linking to
their downloads, which is why it lives here.

It holds the full General MIDI set (pianos, electric pianos, organs, guitars, basses, strings, brass,
woodwinds, synths, pads, ethnic and percussion instruments) plus drum kits.
